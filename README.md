# AI Engineering Journey Tracker

An interactive, browser-based 90-day learning curriculum and progress dashboard designed to transition individuals from non-technical backgrounds (business, admin, finance) into job-ready freelance AI Engineers.

The roadmap enforces an **80% building / 20% theory** split, focusing on practical client outcomes, automation workflows, LLM integrations, and production-grade deployments.

* **Live Tracker:** https://dan2mcdr.github.io/AI-Engineer-Journey/

---

## ⚡ Features

* **90-Day Curriculum**: Structured across 10 stages covering everything from Python fundamentals to vector databases, AI agents, and production deployment.
* **Progress Tracking**: Monitors overall progress percentage, completed days, total days, and consecutive daily streaks.
* **Local Storage Persistence**: Progress automatically saves directly to the browser's `localStorage`.
* **Interactive Dashboard**: Expandable weekly modules and daily task cards complete with curated learning resources and direct links.
* **Responsive Dark UI**: Designed with a developer-focused, dark-themed interface built using modern CSS variables and Grid layout.

---

## 🗺️ Roadmap Overview

| Stage | Focus Area | Goal |
| :--- | :--- | :--- |
| **Stage 0** | Orientation (Days 1–7) | Understand the AI Engineering ecosystem and core concepts. |
| **Stage 1** | Python Foundations (Days 8–21) | Write functional Python scripts, manage virtual environments, and use Git. |
| **Stage 2** | API Engineering (Days 22–35) | Master REST APIs, authentication patterns, webhooks, and third-party integrations. |
| **Stage 3** | Automation Engineering (Days 36–49) | Master n8n workflow design, error handling, and business process automation. |
| **Stage 4** | LLM Engineering (Days 50–63) | Learn prompt engineering, tool calling, JSON mode, and evaluation techniques. |
| **Stage 5** | RAG & Knowledge Systems (Days 64–70) | Build document Q&A pipelines using embeddings and vector databases. |
| **Stage 6** | AI Agents (Days 71–77) | Design autonomous agents with tool loops, memory, and safety gates. |
| **Stage 7–8** | Databases & Backend (Days 78–84) | Model relational data in SQL/Supabase and expose endpoints via FastAPI. |
| **Stage 9–10** | Deploy & Production (Days 85–90) | Containerize apps with Docker, set up CI/CD, and launch client services. |

---

## 🛠️ Tech Stack

* **Frontend**: Vanilla HTML5, CSS3 (Custom Properties, Flexbox, Grid), Modern JavaScript (ES6+).
* **Data Storage**: Browser `localStorage` API.
* **Dependencies**: None — fully standalone without external frameworks or npm dependencies.
