# AI Engineering Journey Tracker

An interactive, browser-based 90-day learning curriculum and progress dashboard designed to transition individuals from non-technical backgrounds (business, admin, finance) into job-ready freelance AI Engineers.

The roadmap enforces an **80% building / 20% theory** split, focusing on practical client outcomes, automation workflows, LLM integrations, and production-grade deployments[cite: 1].

* **Live Tracker:** [https://dan2mcdr.github.io/ai-engineer-journey/](https://dan2mcdr.github.io/ai-engineer-journey/)

---

## ⚡ Features

* **90-Day Curriculum**: Structured across 10 stages covering everything from Python fundamentals to vector databases, AI agents, and production deployment[cite: 1].
* **Progress Tracking**: Monitors overall progress percentage, completed days, total days, and consecutive daily streaks[cite: 1].
* **Local Storage Persistence**: Progress automatically saves directly to the browser's `localStorage`[cite: 1].
* **Interactive Dashboard**: Expandable weekly modules and daily task cards complete with curated learning resources and direct links[cite: 1].
* **Responsive Dark UI**: Designed with a developer-focused, dark-themed interface built using modern CSS variables and Grid layout[cite: 1].

## 🗺️ Roadmap Overview

| Stage | Focus Area | Goal |
| :--- | :--- | :--- |
| **Stage 0** | Orientation (Days 1–7)[cite: 1] | Understand the AI Engineering ecosystem and core concepts[cite: 1]. |
| **Stage 1** | Python Foundations (Days 8–21)[cite: 1] | Write functional Python scripts, manage virtual environments, and use Git[cite: 1]. |
| **Stage 2** | API Engineering (Days 22–35)[cite: 1] | Master REST APIs, authentication patterns, webhooks, and third-party integrations[cite: 1]. |
| **Stage 3** | Automation Engineering (Days 36–49)[cite: 1] | Master n8n workflow design, error handling, and business process automation[cite: 1]. |
| **Stage 4** | LLM Engineering (Days 50–63)[cite: 1] | Learn prompt engineering, tool calling, JSON mode, and evaluation techniques[cite: 1]. |
| **Stage 5** | RAG & Knowledge Systems (Days 64–70)[cite: 1] | Build document Q&A pipelines using embeddings and vector databases[cite: 1]. |
| **Stage 6** | AI Agents (Days 71–77)[cite: 1] | Design autonomous agents with tool loops, memory, and safety gates[cite: 1]. |
| **Stage 7–8** | Databases & Backend (Days 78–84)[cite: 1] | Model relational data in SQL/Supabase and expose endpoints via FastAPI[cite: 1]. |
| **Stage 9–10** | Deploy & Production (Days 85–90)[cite: 1] | Containerize apps with Docker, set up CI/CD, and launch client services[cite: 1]. |

* **Data Storage**: Browser `localStorage` API[cite: 1].
* **Dependencies**: None — fully standalone without external frameworks or npm dependencies[cite: 1].
